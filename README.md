# 伊尔明苏尔档案：提瓦特编年史

《原神》世界观的编年史视频，约 13 分半，中文旁白和字幕，3840×2160 / 60 fps。时间线从「天」到来之前的龙之世讲起，经过白鸽衔枝、葬火之年、魔神战争、无神之国、坎瑞亚灾变和之后的五百年，一直讲到旅行者踏入至冬（7.0，2026 年 8 月）。

**片中所有画面都由代码实时渲染。** 没有游戏素材，没有 AI 生成的图像，没有手绘帧。每一帧都是时间的确定性函数，用 GLSL 着色器、GPU 线条和 Canvas2D 排版画出来。配乐同样从零合成，没有采样，也没有用生成模型。

## 画面语言

整部片的样式是「档案里的发光版画」：

- **天空**：一个参数化的着色器，包括星云、星河、主光与光芒、三轮月亮、极光、云层、能倒映光的海、深渊裂隙，以及会龟裂的「虚假之天」。
- **大地与建筑**：用路径写成的剪影，在着色器里做景深雾、版画排线和迎光边缘，轮廓线会在画面出现时从左到右「刻写」出来。
- **线描主体**：七元素龙王、风龙与杜林、世界树、天钉、空之执政的立方体、以棋子形状铸成的神之心、四影与七元素的徽记（本片自绘的几何纹样）、碎裂的月亮、深渊的触须。
- **排版**：字幕、按旁白逐字点亮的《日月前事》引文卡、带年代标尺的章节卡、地名签、片头和片尾。

## 声音

- **旁白**：Edge TTS，云健朗读正文，晓晓朗读《日月前事》的引文。
- **配乐**（`pipeline/music.py`）：弦乐垫音、共振峰「人声」、FM 钢片琴与钟、拨弦、低音持续音、太鼓、撞击声，最后过一层合成的厅堂混响。旁白出现时，配乐的低频段压低 12 dB，高频段压低 6 dB。
