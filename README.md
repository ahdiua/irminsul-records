# 提瓦特编年史

《原神》世界观的编年史视频，约 15 分钟，中文旁白和字幕，3840×2160 / 60 fps。时间线从「天」到来之前的龙之世讲起，经过白鸽衔枝、葬火之年、魔神战争、无神之国、坎瑞亚灾变和之后的五百年，一直讲到旅行者踏入至冬（7.0，2026 年 8 月）。

**片中所有画面都由代码实时渲染。** 没有 AI 生成的图像，没有手绘帧；游戏素材只用了两样：七元素徽记的矢量图形和游戏字体汉仪润圆 65W。每一帧都是时间的确定性函数，用 GLSL 着色器、GPU 线条和 Canvas2D 排版画出来。配乐同样从零合成，没有采样，也没有用生成模型。

## 成片

- `out/teyvat-chronicle-4k.mp4`：3840×2160，60 fps，HEVC Main10，AAC 256k，14 分 39 秒。只出这一个版本。
- `out/cover.jpg`（1920×1080）和 `out/cover-4k.png`：视频封面，取自片头标题卡。

## 画面语言

整部片的样式是「史书里的发光版画」：

- **天空**：一个参数化的着色器，包括星云、星河、主光与光芒、三轮月亮、极光、云层、能倒映光的海、深渊裂隙，以及会龟裂的「虚假之天」。
- **大地与建筑**：用路径写成的剪影，在着色器里做景深雾、版画排线和迎光边缘，轮廓线会在画面出现时从左到右「刻写」出来。
- **线描主体**：七元素龙王、风龙与杜林、世界树、天钉、空之执政的立方体、以棋子形状铸成的神之心、七元素徽记、根源之轮上的四个轮回、碎裂的月亮、深渊的触须。
- **排版**：字幕、按旁白逐字点亮的《日月前事》引文卡、带年代标尺的章节卡、地名签、片头和片尾。

## 声音

- **旁白**：Gemini 3.8 Flash TTS，Schedar 朗读正文，Aoede 朗读《日月前事》的引文。
- **配乐**（`pipeline/music.py`）：弦乐垫音、共振峰「人声」、FM 钢片琴与钟、拨弦、低音持续音、太鼓、撞击声，最后过一层合成的厅堂混响。旁白出现时，配乐的低频段压低 12 dB，高频段压低 6 dB。

## 环境要求

- Windows + PowerShell 7（渲染脚本是 `.ps1`）。
- [Bun](https://bun.sh) 1.x，在 `app/` 下执行一次 `bun install`。
- Google Chrome：预览用它打开，渲染时由 Playwright 驱动无头 Chrome。
- FFmpeg（需在 PATH 中）；4K 渲染用 `hevc_nvenc`，需要支持 HEVC 10-bit 编码的 NVIDIA 显卡。
- 只有修改旁白稿后重新生成声音和数据时才需要：[uv](https://docs.astral.sh/uv/) 和 Python 3.12（在仓库根目录执行 `uv sync`；对齐用的 torch 是 CUDA 12.8 版本），以及 Vertex AI 服务账号密钥 `secrets/gcp_key.json`（不进仓库）。仓库里已经带有生成好的音轨和数据，只预览或渲染不需要这些。

## 运行预览

```powershell
cd app
$env:PDOOM_NO_HMR = '1'
bunx --bun vite --port 5190 --strictPort --host 127.0.0.1
```

用 Chrome 打开 http://127.0.0.1:5190 。要从局域网其他设备访问，把 `--host` 改成 `0.0.0.0`。

## 渲染

保持上面的预览服务开着，然后在仓库根目录执行：

```powershell
pwsh -File pipeline/render_final.ps1
```

脚本分 4 段并行渲染 4K60 画面，再无损拼接并封装 `audio/chronicle.m4a`，输出 `out/teyvat-chronicle-4k.mp4`，耗时约 45 分钟。并行渲染占用内存较多。
