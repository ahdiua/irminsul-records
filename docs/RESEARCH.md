## 2026-10-28 核查（萌娘百科 → BWIKI / 观测枢 复核）

片中据此改过的说法（旧 → 新）：罗诺瓦 → 若娜瓦（两处台词 + 四影示意图）；「天梯」→「天蛇船」系住的长索；
三月「落入天理掌控」→ 与天理立下和约；「三位月之女神就此陨落」→「三团银辉，从此只余其一」；白夜国在大战中坠入海渊
（不是天钉）、禁令使其找不到归途；层岩巨渊 →「天星」坠落（《绝云记闻》原文）；暴风之神 → 龙卷之魔神；温迪不是
「借走了诗人的名字」（少年无名）；3700 年前是璃月建国，不是归终之死；奥罗巴斯死于雷电将军「无想的一刀」（不确指影）；
纳塔「从未卷入战争 / 两千年前」→ 修库特尔葬火后重新统治、希巴拉克击败他（不注年代）；「冰雪中的皇帝」→ 白沙皇；
「黑海的孤岛」→ 暗之外海；赤月王朝崇拜「赤月之骸」（不是「与深渊相连的血色之月」）；双子：「天空回应了招唤」，
不再说「在撞击中失散 / 先醒来的那一位」；丘丘人诅咒与若娜瓦的不死诅咒分开说；「黑龙」→「黄金」造出的魔龙杜林；
厄歌莉娅不说「在枫丹」陨落；玛薇卡「把生命存入圣火」；纳塔结尾「延续了五百年的夜之战争」→「旷日持久的战争」；
挪德卡莱「第四轮月亮的残骸」→「未能成为月亮的残骸」；光界 → 光界力；卷二标题「白鸽衔枝」→「鸽子衔枝」（《日月前事》）。

旧世界树已在空月之歌第十幕被焚毁、由阿如接替：序章改为「曾生长着」，尾声（ruins_sky）加一句「就在不久前，被
「博士」污染的世界树在火中燃尽；它的职责，由赤王留下的「阿如」接了过去」（用户同意的方案）。

沙尔·芬德尼尔的年代：Fandom、BWIKI、萌娘百科（坎瑞亚）都放在葬火之战后（约 6000 年前），但亲历其覆灭的伊蒙洛卡
又参加了 2600 年前的蒙德革命，社区没有定论；片中按前者。

## 有意没有采用的说法

- 「尼伯龙根与星球一同诞生」：最初只见于萌娘百科；BWIKI 引空月之歌文本「伴随世界诞生……的始源之龙」，可采用，但片中不需要。
- 「火龙帝国」「（与深渊）绵延千年的战争」：只见于萌娘百科，BWIKI 无此说法。
- 末代国王「伊尔明苏尔」：萌娘百科的写法，与游戏文本（伊尔明）不符。
- 「遗迹守卫是为了对抗神明而造」：Fandom 标注为推测。
- 7.x 至冬主线的具体剧透（各方百科说法未统一）：片中只交代旅行者已抵达至冬，女皇的目标是挑战天理。
- 第三位降临者的名字（Saarelainen）：中文译名还没核实，片中只说「另一位『降临者』」。
- 萌娘百科称坎瑞亚人为第三降临者与安娜丝塔夏的后裔（7.x）：片中仍只说「一群不再信仰神明的人」。
